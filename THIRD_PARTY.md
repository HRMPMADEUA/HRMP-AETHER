# Third-party components

- **AndroidLibXrayLite / Xray core** — https://github.com/2dust/AndroidLibXrayLite — LGPL-3.0. Downloaded by CI as `libv2ray.aar`.
- **WG Tunnel core** — https://github.com/wgtunnel/core — MIT and upstream bundled third-party notices.

Keep upstream licenses and notices with any redistributed build and check the exact release's license obligations before distribution.

## DNS tunnel engines added/used by TIREXNET

- **MasterDnsVPN** — https://github.com/masterking32/MasterDnsVPN — built by CI as `libmasterdnsvpn.so`; upstream LICENSE is copied to `assets/third_party/MASTERDNSVPN-LICENSE.txt` at build time. Verify its terms before redistribution.
- **StormDNS** — https://github.com/nullroute1970/StormDNS — built by CI as `libstormdns.so`.
- **CottenDNS** — https://github.com/WhiteDNS/CottenDNS — MIT; license copied by CI.
- **SlipNet** (DNSTT / VayDNS / Soar runtime, AGPL-3.0) — https://github.com/anonvector/SlipNet — license shipped as `SLIPNET-AGPL-3.0.txt`.
